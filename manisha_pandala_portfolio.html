Cybersecurity Research | Zero Trust | Explainable Threat Detection

CyberGuard: Third-Party Data Breach Analysis

The 2025 Verizon DBIR found that third-party involvement in breaches doubled to 30%; it also recorded 3,336 security incidents in the financial and insurance sector, including 927 with confirmed data disclosure. I used that risk landscape to study how financial institutions can evaluate vendor access without relying on an opaque model.

Research Question

How can Zero Trust Architecture, vendor verification, compliance controls, and continuous monitoring reduce the risk created by trusted third-party access?

System Design

Built a deterministic expert system for single-event and bounded batch classification, explainable 0-100 risk scoring, audit reasons, and mappings to Zero Trust principles and selected NIST SP 800-53 controls.

Case Study

Examined the 2024 Western Alliance Bank breach involving Cleo's managed file-transfer system to assess continuous verification, least-privilege vendor access, and layered security controls.

Design decision: CyberGuard uses traceable rules so each classification can be tied to a specific condition. The public build passes 42 automated tests and exercises six attack categories across a deterministic 5,000-event scale check. Future work proposes a hybrid layer using SVM and Random Forest anomaly detection.

Open Pixel | SQL, Python, Data Validation

Operational Data Quality Pipeline

Problem
Team reports depended on raw operational data that needed better validation before it could be trusted for business decisions.
Process
Built a Python validation contract for identifiers, duplicates, customer fields, email structure, non-negative amounts, controlled statuses, and dates, with an auditable repair log.
Result
On a deterministic 10,000-row generated dataset, raised the strict fully-valid-row score from 75.4% to 100%—a 24.6-point lift—while preserving every repair count.

Information Retrieval | TF-IDF, Cosine Similarity, Flask

Semantic Search & Similarity Detection

Problem
Exact keyword lookup made related documents harder to rank and gave reviewers little evidence for why two passages were considered similar.
Process
Built a deterministic retrieval baseline using normalized word and phrase vectors, cosine ranking, a Flask API, and sentence-level similarity evidence.
Result
Validated the public pipeline with nine tests and a generated 10,000-document scale check: forty repeatable queries achieved a 100% top-1 topic match with 0.88 ms median local latency.

Computer Vision | OpenCV, Isolation Forest, Explainability

Battery Cell Anomaly Detection

Problem
Battery inspection workflows need fast visual signals that help teams prioritize potentially defective cells for review.
Process
Built a geometry-preserving CT pipeline that aligns collector tabs, combines radial and axial views, extracts interpretable geometry features, ranks unusual cells with Isolation Forest, and produces occlusion maps.
Result
Packaged the workflow as a reproducible public project with 11 automated tests and a deterministic 32-cell synthetic validation. Evaluation on real CT data is the next stage.
